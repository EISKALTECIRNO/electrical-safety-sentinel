# 电安哨兵 Wokwi 仿真验收包

## 本包内容
- `sketch.ino`：ESP32-S3 固件主程序（手动场景演示版）
- `diagram.json`：Wokwi 电路连接
- `libraries.txt`：Wokwi 所需库
- `wokwi-project.txt`：原 Wokwi 项目来源

## 本版调整
1. 默认关闭自动脉冲、自动故障和自动篡改演示，避免多个事件同时发生，便于逐项演示和验收。
2. 增加串口手动负载档位：5 W、10 W、12 W。
3. 保留原有热模型、接触温升残差、分级状态、故障锁存、长按确认、Preferences 状态恢复、SHA-256 哈希链与篡改演示。
4. 串口启动信息会列出全部操作命令。

## Wokwi 操作
1. 在 Wokwi 打开项目，将本包中的 `sketch.ino`、`diagram.json`、`libraries.txt` 分别替换到对应文件。
2. 启动仿真，打开 Serial Monitor，波特率 115200。
3. 首次测试若继承了旧的报警/故障状态，在串口输入 `c` 清除保存状态并重启。

## 串口命令
| 命令 | 功能 |
|---|---|
| `0` | 设置 5 W 正常负载 |
| `1` | 设置 10 W 接触劣化测试负载 |
| `2` | 设置 12 W 热模型报警测试负载 |
| `a` | 注入 200 ms 极值脉冲，预期不锁存 |
| `b` | 注入 800 ms 极值脉冲，预期触发 E-01 |
| `d` | 切换接触良好/劣化模拟 |
| `m` | 切换计量故障 |
| `t` | 切换温度故障 |
| `s` | 切换存储故障模拟 |
| `v` | 验证当前哈希链 |
| `k` | 保存当前链头前 8 位作为本次演示锚点 |
| `x` | 篡改一条日志，不重算后续哈希 |
| `y` | 篡改日志并重算后续哈希，用锚点检出整体重写 |
| `u` | 恢复篡改前日志 |
| `e` | 导出日志到串口 |
| `p` | 保存状态并模拟掉电重启 |
| `c` | 清除 Preferences 保存状态并重启 |
| `?` | 显示命令帮助 |

## 建议演示顺序

### 1. 正常状态
- 输入 `c` 重启清场。
- 默认 5 W，观察 OLED `[SIM]`、串口 `[DATA] src=SIM` 和绿灯心跳。

### 2. 极值脉冲判定
- 输入 `a`：应看到 200 ms `SURGE` 记录，不应触发 E-01。
- 输入 `c` 清场重启。
- 输入 `b`：应在 500 ms 确认逻辑处触发 `E-01`，红灯亮并锁存。

### 3. 热模型报警
- 输入 `c` 清场重启，再输入 `2`（12 W）。
- 观察 theta 上升，先进入 WARN，随后触发 `T-01`。
- 本仿真时钟约为真实等待时间的 10 倍；以串口 `simT` 和状态事件为准。

### 4. 接触劣化
- 输入 `c` 清场重启，输入 `1`（10 W），再输入 `d` 开启接触劣化。
- 观察残差 `r` 增大并进入接触预警，持续后触发 `C-01`。
- 该过程需要等待热模型累积，约几十秒真实时间；若要重新测试，输入 `c`。

### 5. 故障导向安全
- 输入 `c` 清场重启，输入 `m` / `t` / `s` 分别模拟计量、温度、存储故障。
- 故障锁存后关闭对应故障（再次输入同一命令），等待自检稳定，再长按板载按钮约 2 秒进行现场确认。
- 故障期间绿灯不应显示正常状态。

### 6. 哈希链与锚定
- 输入 `a` 产生事件记录；输入 `k` 保存锚点；输入 `v` 应显示 VERIFY OK。
- 输入 `x`，再输入 `v`，应显示 VERIFY FAIL。
- 输入 `u` 恢复后再次 `v`，应显示 VERIFY OK。
- 可再输入 `y` 后 `v`，观察链内部重算后仍因锚点不一致而失败；最后 `u` 恢复。

### 7. 掉电恢复
- 先用 `b` 触发报警锁存，再输入 `p` 模拟掉电重启。
- 启动信息应显示恢复的报警状态与热状态。
- 输入 `c` 可清除保存状态，重新开始演示。

## 当前仿真边界（必须如实标注）
- 数据源是 SIM，不是 INA226 / DS18B20 实测。
- 脉冲注入采用软件计时循环演示确认逻辑，不等于已经完成真实 50 Hz 硬件采样性能测试。
- 日志链保存在 RAM；Preferences 保存的是部分运行状态，不是完整日志链。重启后不能声称历史哈希日志已持久保存。
- 当前工程未实现申报书中的只读网页、完整曲线事件回放、PC 端校验脚本与真实 SD 卡记录。
- 申报书 T1–T18 中涉及真实测量误差、真实采样率、网络权限、SD 卡、事件回放等项目，不能仅凭本 Wokwi 工程判定通过。
- 所有结果标注为仿真；不用于真实设备安全判定，不接触 220 V 市电。
